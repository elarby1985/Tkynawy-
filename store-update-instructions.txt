TO ADD A REAL PHOTO:
1. Put the photo in: store/product-images/
2. Example filename: iphone-16-pro-max.jpg
3. In products.json set: "image": "iphone-16-pro-max.jpg"

NO EMOJI PRODUCT IMAGES:
If no photo is entered, a clean Tyknawy branded placeholder is shown.

PRICE:

STOCK:

"status": "reserved"
"status": "sold"

STORAGE OPTIONS
Each iPhone can now have multiple storage sizes in the SAME product card.

Example inside store/products.json:

"storage_options": [
  {"storage": "128GB", "price": 1800, "status": "in_stock"},
  {"storage": "256GB", "price": 2050, "status": "in_stock"},
  {"storage": "512GB", "price": 2450, "status": "sold"}
]

When the customer clicks a storage size:
- the displayed price changes
- the selected storage is added to the WhatsApp inquiry
- sold storage options are disabled

This works in both English and Arabic from the same products.json file.
